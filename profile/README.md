## Areaform

Plans of any place, an exhibition hall, an office, a shop, a warehouse, a café, drawn once and shown on any site, in 2D and 3D, with wayfinding inside.

- **[areaform/areaform](https://github.com/areaform/areaform)**: the open engine. The data model, the View to embed, the Editor, wayfinding and an MCP server that turns a Figma frame or an image into a first draft.
- **[areaform.app](https://areaform.app)**: the hosted builder. Draw a plan, publish it, embed it with one snippet.

```sh
npm install @areaform/view three
```

Questions go to [Discussions](https://github.com/areaform/areaform/discussions), bugs to [issues](https://github.com/areaform/areaform/issues), everything else to hello@areaform.app.
